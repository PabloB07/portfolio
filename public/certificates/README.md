# Certificates Directory

This directory contains certificate PDF files for the portfolio.

## Instructions

Place your certificate PDFs here with the following naming convention:
- `ruby-rails.pdf`
- `javascript.pdf`
- `react.pdf`
- `nextjs.pdf`

Or update the file names in `/src/data/portfolio.ts` to match your actual certificate file names.

The certificates section will display these files when users click "View Certificate" buttons.
